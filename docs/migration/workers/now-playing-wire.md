# Private now-playing bridge

The retained Svelte preload API still sends `MAIN.NOW_PLAYING`, `NOW_PLAYING_UNSET` and `OPEN_NOW_PLAYING` and returns `undefined`. The desktop adapter snapshots supported data and the full runtime/library/path context synchronously before entering native IPC. It sends raw bytes to the dedicated parser; a generic JSON IPC round trip would lose nonfinite duration values.

`nowPlayingWire.ts` and `now_playing_input.rs` carry every numeric duration through a private finite/NaN/infinity/negative-zero tag and an own-null placeholder in the payload. Native code restores that numeric value separately before planning. Missing or own-undefined duration stays absent. Non-enumerable duration is omitted, matching an actual MessagePort clone. Dense arrays require enumerable data properties; unsupported descriptors, getters, cycles, nested undefined/nonfinite values and lone UTF-16 surrogates are rejected explicitly. The decoder rejects duplicate keys and ambiguous schemas, preserves correctly rounded finite numbers and never grants file authority. Payloads are bounded to 64 KiB, 1024 value nodes and depth eight; the raw frame is capped at 256 KiB. Existing source inputs outside these limits remain a capability gap.

Original `AUDIO_METADATA` and missing-file `ALERT` messages retain their original payloads and absent listener IDs. Context, one-use delivery ID, process-wide decimal sequence and typed metadata restoration travel outside the source message. The bridge validates full context before restoration, rejects replay and restores actual `Uint8Array`, own undefined, special numbers and declared property order before invoking original receivers. Invalid restoration is atomic and receives a negative private completion. Private completions never become source success callbacks. Complete common-object insertion-order parity remains unverified where native cover extraction appends `picture`; per-picture field order is covered separately.

Four entered command promises and four entered completion promises remain charged until actual settlement, including reentrant delivery, context retirement and lost responses. A bounded retirement observer timeout keeps the same entered native promise for retry. Terminal close also waits for captured owners when the current context disappears; missing context is not evidence of drain. Native CLOSE remains attempted after a settled frontend retirement error.

Focused verification on 2026-10-19: 58 Node tests across the shared bridge, wire, independent real-MessagePort descriptor checks and dedicated now-playing bridge pass; focused TypeScript checking passes. Five native parser tests include actual TS-produced raw bytes and all six tested IEEE duration identities. These checks certify the transport slice, not complete now-playing desktop behavior or performance. Real native composition and GUI evidence are tracked separately.
